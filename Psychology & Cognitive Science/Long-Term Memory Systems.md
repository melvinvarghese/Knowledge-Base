# Long-Term Memory Systems

## Overview
Long-term memory is the brain's vast, enduring archive of skills, facts, and personal experiences. Far from a single filing cabinet, cognitive neuroscience reveals multiple dissociable memory systems supported by distinct neural circuits, each operating under different rules of encoding, storage, and retrieval.

## Core Mechanics & Foundations
The foundational taxonomy, illuminated by Brenda Milner's studies of patient H.M. (Henry Molaison, who lost the ability to form new conscious memories after bilateral hippocampal removal in 1953), divides long-term memory into declarative (explicit) and non-declarative (implicit) systems. Endel Tulving further split declarative memory into episodic memory (autobiographical events anchored in time and place, accompanied by 'mental time travel') and semantic memory (general world knowledge, vocabulary, and concepts stripped of personal context).

## Modern Applications & Advanced Significance
Non-declarative memory operates largely outside conscious awareness and survives hippocampal damage. It includes procedural memory (motor skills like riding a bike, governed by the basal ganglia and cerebellum), perceptual priming (faster identification of previously encountered stimuli), and classical conditioning (emotional or reflexive associations involving the amygdala). Effective encoding into declarative memory relies heavily on 'levels of processing' (Craik and Lockhart, 1972): deep semantic elaboration and self-reference yield far stronger recall than shallow phonetic or visual rehearsal.

## Real-World Impact & Systems
Understanding dissociable memory systems transformed clinical neurology, education, and aging research. Spaced repetition and retrieval practice ('the testing effect') leverage encoding and consolidation dynamics to dramatically boost durable academic learning, while Alzheimer's disease and amnesia selectively devastate episodic encoding while sparing early procedural habits.

## Key Terminology
- **Episodic memory**: Explicit memory for personally experienced events situated in specific time and spatial context.
- **Semantic memory**: Explicit memory for general facts, concepts, and language independent of personal learning context.
- **Procedural memory**: Implicit memory for motor skills, habits, and cognitive routines acquired through practice.
- **Levels of processing**: Principle that deeper, meaning-based encoding produces stronger long-term memory than shallow surface rehearsal.
- **Testing effect**: Empirical finding that actively retrieving information from memory strengthens retention more than passive re-reading.
- **Priming**: Implicit facilitation where prior exposure to a stimulus speeds or biases subsequent processing.
