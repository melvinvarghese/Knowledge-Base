# Working Memory and Executive Function

## Overview
Working memory is the brain's limited-capacity workspace for temporarily holding and manipulating information needed for reasoning, comprehension, and goal-directed action. Closely tied to executive functions governed by the prefrontal cortex, it acts as the cognitive bottleneck through which conscious thought flows.

## Core Mechanics & Foundations
Early 'short-term memory' models (Atkinson and Shiffrin, 1968) pictured a passive unitary buffer holding roughly 7±2 items for ~20 seconds before decay or transfer to long-term storage. In 1974, Alan Baddeley and Graham Hitch replaced this passive store with a dynamic multi-component Working Memory model: a 'central executive' directing attention, a 'phonological loop' rehearsing verbal/auditory speech, a 'visuospatial sketchpad' holding spatial imagery, and an 'episodic buffer' (added in 2000) binding multimodal chunks into coherent chronological episodes.

## Modern Applications & Advanced Significance
Executive functions represent the top-down control processes operating on working memory, commonly divided by Miyake and Friedman into three core abilities: inhibition (suppressing prepotent impulses or distractors), shifting (switching flexibly between tasks or mental sets), and updating (monitoring and refreshing working memory contents). Nelson Cowan later refined capacity estimates, showing that pure focused attention holds only about 3 to 4 unchunked items simultaneously unless grouped strategically via chunking.

## Real-World Impact & Systems
Working memory capacity strongly predicts fluid intelligence, reading comprehension, mathematical problem-solving, and academic achievement. Deficits in executive control characterize ADHD, schizophrenia, traumatic frontal-lobe injury, and age-related cognitive decline, driving targeted interventions like cognitive offloading and structured environmental scaffolding.

## Key Terminology
- **Phonological loop**: Working memory subsystem maintaining verbal and acoustic information via silent articulatory rehearsal.
- **Visuospatial sketchpad**: Working memory subsystem holding and manipulating visual appearance and spatial locations.
- **Central executive**: Attentional control system coordinating subsystems, suppressing interference, and allocating cognitive resources.
- **Cognitive load**: Total working memory demand imposed by a task; exceeding capacity degrades learning and performance.
- **Inhibitory control**: Executive ability to override automatic habits, temptations, or irrelevant distractions.
- **Task switching**: Executive process of reconfiguring mental rules when alternating between different cognitive tasks, incurring switch costs.
