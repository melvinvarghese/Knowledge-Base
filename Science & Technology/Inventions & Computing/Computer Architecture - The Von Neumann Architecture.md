# Computer Architecture - The Von Neumann Architecture

> **The Big Idea:** The theoretical computing framework formulated by John von Neumann in 1945 separating processing hardware from stored memory.

---

## 1. What It Is
The theoretical computing framework formulated by John von Neumann in 1945 separating processing hardware from stored memory.

## 2. How It Works & Key Insights
- **Core Mechanism:** Consists of a CPU (ALU and registers), a control unit, primary RAM memory holding both instructions and data, and secondary I/O storage.
- **Scientific Foundation:** In the study of inventions & computing, this concept represents a fundamental pillar of physical reality and natural order.
- **Detailed Mechanics:**
```
Control Unit -> Fetches Instruction from Memory -> ALU Executes -> Writes to Registers/RAM
```
