# Cryptography and Public-Key Encryption (RSA)

> **The Big Idea:** The mathematical techniques used to secure communications against eavesdropping across public, untrusted networks.

---

## 1. What It Is
The mathematical techniques used to secure communications against eavesdropping across public, untrusted networks.

## 2. How It Works & Key Insights
- **Core Mechanism:** Diffie-Hellman and RSA introduced asymmetric encryption: anyone can encrypt with a public key, but only the private key mathematically decrypts it.
- **Scientific Foundation:** In the study of inventions & computing, this concept represents a fundamental pillar of physical reality and natural order.
- **Detailed Mechanics:**
```
Plaintext Message -> Encrypted with Public Key -> Ciphertext Wire -> Decrypted with Private Key
```
