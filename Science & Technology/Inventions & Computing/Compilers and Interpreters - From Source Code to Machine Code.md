# Compilers and Interpreters - From Source Code to Machine Code

## Overview
Compilers and Interpreters are translation programs that convert human-readable high-level source code into low-level machine instructions or execute code directly.

---

## 1. Theoretical Foundations & Governing Principles
The Compiler Pipeline Stages: 1. Lexical Analysis (tokenization); 2. Syntax Analysis (parsing into Abstract Syntax Trees); 3. Semantic Analysis (type checking); 4. Optimization (dead code elimination); 5. Code Generation (assembly/machine code).

---

## 2. Structural Mechanics & Scientific Analysis
Ahead-Of-Time (AOT) vs Just-In-Time (JIT): AOT compilers (C++, Rust) generate native binary executables prior to deployment; JIT compilers (JVM, V8 JavaScript) compile bytecode into native machine instructions dynamically at runtime.

---

## 3. Real-World Applications & Technological Impact
Software development toolchains (GCC, Clang/LLVM), browser JavaScript execution engines, and mobile application compilation.

---

## Key Terms
- **Abstract Syntax Tree (AST)**: Hierarchical tree representation of the abstract syntactic structure of source code.
- **Intermediate Representation (IR)**: Universal code representation used internally by a compiler between front-end and back-end.
- **Just-In-Time (JIT)**: Compilation method translating bytecode into native machine code at runtime.
