# Hash Functions and Cryptographic SHA-256

## Overview
A Cryptographic Hash Function is a deterministic one-way algorithm that maps arbitrary-length input data into a fixed-size bit string, essential for data integrity verification and authentication.

---

## 1. Theoretical Foundations & Governing Principles
The Three Crucial Properties: 1. Pre-image Resistance (one-way: impossible to deduce input from hash); 2. Second Pre-image Resistance (impossible to find matching alternate input); 3. Collision Resistance (impossible to find any two inputs producing identical hash).

---

## 2. Structural Mechanics & Scientific Analysis
The Avalanche Effect in SHA-256: Changing a single input bit flips approximately 50% of the output 256-bit digest through 64 rounds of non-linear bitwise logical operations (Ch, Maj, $\Sigma$).

---

## 3. Real-World Applications & Technological Impact
Blockchain proof-of-work mining (Bitcoin), Git commit cryptographic hashing, software download checksum verification, and password storage salting.

---

## Key Terms
- **Hash Digest**: Fixed-length hexadecimal output string generated by a cryptographic hash function.
- **Collision Resistance**: Mathematical property ensuring no two distinct inputs yield identical hash digests.
- **Avalanche Effect**: Property where a tiny change in input creates a drastic, random-looking change in output hash.
