# Magnetic Core Memory and the Shift to Solid-State DRAM

## Overview
Magnetic Core Memory was the predominant random-access memory from 1955 to 1975, utilizing tiny ferrite magnetic rings, before being replaced by Robert Dennard's single-transistor solid-state DRAM.

---

## 1. Theoretical Foundations & Governing Principles
Ferrite Ring Magnetic Hysteresis: Cores are magnetized clockwise (Bit 1) or counterclockwise (Bit 0) by orthogonal drive lines ($X, Y$) carrying half-select currents ($I/2$), reading destructive states via a sense wire.

---

## 2. Structural Mechanics & Scientific Analysis
1T1C Dynamic RAM (DRAM): Dennard's 1968 invention uses a single transistor and capacitor per bit cell, periodically refreshed every few milliseconds, delivering gigabytes of dense volatile memory.

---

## 3. Real-World Applications & Technological Impact
Apollo Guidance Computer flight computer memory, early IBM mainframe computers, and modern computer operational RAM.

---

## Key Terms
- **Core Memory**: Early non-volatile computer memory storing bits in magnetized ferrite toroidal rings.
- **Dynamic RAM (DRAM)**: Volatile solid-state computer memory storing bits as charges in microscopic capacitors.
- **Destructive Read**: Memory readout process that erases stored bit values, requiring immediate rewrite.
