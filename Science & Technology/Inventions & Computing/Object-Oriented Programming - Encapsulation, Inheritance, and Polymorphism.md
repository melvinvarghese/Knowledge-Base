# Object-Oriented Programming - Encapsulation, Inheritance, and Polymorphism

## Overview
Object-Oriented Programming (OOP) is a software design paradigm that structures program architecture around 'objects'—discrete entities containing data fields (attributes) and associated code methods.

---

## 1. Theoretical Foundations & Governing Principles
The Four Pillars of OOP: 1. Encapsulation (hiding internal state behind public interfaces); 2. Abstraction (simplifying complex reality); 3. Inheritance (subclasses inheriting base class behavior); 4. Polymorphism (uniform method invocation across varied types).

---

## 2. Structural Mechanics & Scientific Analysis
Dynamic Dispatch & Virtual Method Tables: Compilers construct vtables to resolve overridden method pointers at runtime based on the actual instantiated object type.

---

## 3. Real-World Applications & Technological Impact
Enterprise software frameworks (Java, C#), graphical user interface (GUI) development, and large-scale game engine architectures (C++).

---

## Key Terms
- **Encapsulation**: Bundling data with methods operating on that data and restricting direct outside access.
- **Polymorphism**: Ability of varied data types to be manipulated through a common standardized interface.
- **Virtual Method Table (vtable)**: Internal lookup mechanism supporting dynamic runtime method dispatch in OOP.
