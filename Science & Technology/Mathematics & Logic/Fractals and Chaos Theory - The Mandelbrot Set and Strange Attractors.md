# Fractals and Chaos Theory - The Mandelbrot Set and Strange Attractors

## Overview
Chaos Theory and Fractal Geometry study nonlinear dynamical systems that exhibit sensitive dependence on initial conditions alongside self-similar fractional geometric dimensionality.

## Core Mechanics & Foundations
The Mandelbrot Set Iteration: The Mandelbrot set $\mathcal{M}$ is defined in the complex plane as the set of values $c \in \mathbb{C}$ for which the recursive quadratic polynomial $z_{n+1} = z_n^2 + c$ with seed $z_0 = 0$ does not diverge to infinity as $n \to \infty$ ($|z_n| \le 2$). Its boundary displays infinite nested self-similarity and a Hausdorff dimension of 2.

## Modern Applications & Advanced Significance
Strange Attractors & The Lorenz System: In dissipative chaotic systems (such as the Lorenz atmospheric convection equations $\dot{x} = \sigma(y-x), \dot{y} = x(\rho-z)-y, \dot{z} = xy - \beta z$), trajectories never intersect yet remain confined to a bounded fractal phase-space geometry called a strange attractor with positive Lyapunov exponents.

## Real-World Impact & Systems
Turbulence modeling, algorithmic procedural terrain generation in computer graphics, financial market volatility modeling.

## Key Terminology
- **Mandelbrot Set**: Set of complex numbers $c$ for which the function $z_{n+1} = z_n^2 + c$ remains bounded under iteration.
- **Hausdorff Dimension**: Metric dimension generalising topological dimension to real-valued fractional values for fractals.
- **Strange Attractor**: Fractal phase-space trajectory set towards which a chaotic dynamical system asymptotically converges.
