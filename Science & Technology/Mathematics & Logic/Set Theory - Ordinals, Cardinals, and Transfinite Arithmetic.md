# Set Theory - Ordinals, Cardinals, and Transfinite Arithmetic

## Overview
Transfinite set theory, pioneered by Georg Cantor, formalizes mathematical infinities of differing sizes via ordinal and cardinal numbers.

## Core Mechanics & Foundations
Cardinals vs Ordinals: Cardinal numbers measure set sizes (equinumerosity/bijection: $|A| = |B|$ if there exists a bijection $f: A \to B$). Ordinal numbers generalize well-ordered positional sequences: $0 = \emptyset, 1 = \{0\}, 2 = \{0, 1\}, \dots, \omega = \{0, 1, 2, \dots\}$. Transfinite arithmetic defines operations like $\omega + 1 > \omega$, whereas $1 + \omega = \omega$.

## Modern Applications & Advanced Significance
Cantor's Diagonal Argument & Continuum Hypothesis: Cantor proved that the cardinality of natural numbers $\aleph_0 = |\mathbb{N}|$ is strictly smaller than the continuum of real numbers $\mathfrak{c} = |\mathbb{R}| = 2^{\aleph_0}$. Cantor's Theorem states $|A| < |\mathcal{P}(A)|$ for all sets. The Continuum Hypothesis ($2^{\aleph_0} = \aleph_1$) was proven undecidable under standard ZFC axioms by Gödel (1940) and Cohen (1963).

## Real-World Impact & Systems
Mathematical logic foundations, topology dimensional analysis, computer science type theory.

## Key Terminology
- **Cardinality**: Measure of the 'number of elements' of a set, applicable to both finite and transfinite collections.
- **Ordinal Number**: Representation of the order type of a well-ordered set.
- **Cantor's Diagonal Argument**: Proof technique demonstrating that the set of real numbers cannot be put into one-to-one correspondence with the integers.
