# Model Theory - First-Order Logic, Compactness, and Lowenheim-Skolem

## Overview
Model Theory investigates the mathematical relationship between formal syntax (languages, theories, formulas) and semantic mathematical structures (models, interpretations).

## Core Mechanics & Foundations
The Compactness Theorem: A set of first-order sentences $\Gamma$ has a model if and only if every finite subset of $\Gamma$ has a model. Proved as a corollary of Gödel's Completeness Theorem, Compactness proves the existence of **non-standard models of arithmetic** containing infinite non-standard numbers and hyperreal numbers in non-standard analysis.

## Modern Applications & Advanced Significance
The Löwenheim-Skolem Theorem: If a countable first-order theory has an infinite model, it has models of every infinite cardinality $\kappa \ge \aleph_0$. This yields Skolem's Paradox: Zermelo-Fraenkel set theory (ZFC), which proves the existence of uncountable sets ($|\mathbb{R}| > \aleph_0$), possesses a countable model ($\mathfrak{M}$ with $|\mathfrak{M}| = \aleph_0$).

## Real-World Impact & Systems
Non-standard analysis, database relational query expressive power, algebraic classification of algebraically closed fields.

## Key Terminology
- **Model (Logic)**: Mathematical structure that satisfies all the axioms of a given formal mathematical theory.
- **Compactness Theorem**: Fundamental theorem in mathematical logic stating that a set of first-order sentences has a model if every finite subset has a model.
- **Löwenheim-Skolem Theorem**: Theorem stating that if a first-order theory has an infinite model, it has models of all infinite cardinalities.
